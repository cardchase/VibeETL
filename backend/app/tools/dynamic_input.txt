Dynamic Input Node

Dynamically reads and unions multiple files based on a list of file paths from an upstream node.

Parameters:
- filePathColumn (Column): The column containing the file paths to read.
- fileType (String): Auto-detect, CSV, Excel, JSON, or Parquet.
- onSchemaMismatch (String): Behavior when file schemas do not match exactly:
  * Union (Fill Nulls): Keeps all columns, padding missing data with nulls.
  * Intersect (Drop missing): Keeps only columns present in all files.
  * Strict (Align to Reference): Forces all files to strictly match a provided reference file.
  * Error: Fails execution if schemas do not match exactly.
- referenceFilePath (String): Optional reference template file. Used in Strict mode.

Schema Output: - Dynamic: Evaluated based on the union of all read files or the reference file.
