feat(enterprise): VibeETL v1.1 - Native SSL Integration & UX Polish

This release introduces critical enterprise-readiness features, robustness improvements for cloud connectors, and major bug fixes for the frontend architecture.

Key Features & Updates:
- Enterprise SSL Integration: Integrated `truststore` into the backend engine (`main.py`) to natively leverage the Windows Certificate Store. VibeETL now seamlessly bypasses corporate MITM proxies (like Zscaler) without requiring explicit SSL bypass configurations. Added `truststore` and `pip-system-certs` to `requirements.txt`.
- Frontend Stability: Resolved a severe circular dependency between `App.jsx` and `ToolPalette.jsx` that caused Vite HMR to fail and resulted in blank unrendered nodes on the canvas. Extracted configuration variables to a new `config.js` file.
- Cloud Connector Robustness: Upgraded `google_sheets_input.py` and `google_sheets_output.py` to gracefully intercept `[400]` API errors caused by uploaded Office files (`.xlsx`). The backend now pushes highly descriptive, user-friendly instructions to the canvas, guiding users to convert files to Native Google Sheets.
- Documentation Polish: Bumped release version to v1.1 in `README.md`. Updated `Nodes_Reference.md` to formally document the new enterprise proxy capabilities and added explicit warnings regarding the Native Sheets requirement.
